Backup "in use" is now two independent signals, not one wattage check: (1) off-grid/fault - backup shows active whenever the inverter's own grid_mode/work_mode reports Fault or Off-Grid (the same signal driving the Grid node's crossed-out-bus/red-icon logic), regardless of wattage, since that's a real physical voltage-loss detection, not a derived estimate. This is confirmed against a real 21-day-window outage (2026-08-20, vgrid dropped to 0V) - see the last scenario. (2) On-grid wattage threshold - only used while the grid connection is normal, to tell idle CT-crosstalk noise apart from genuine continuous backup load (e.g. an install with backup permanently wired to a fridge/router). Pick a mode below.

Regression fit against 21 days of production data, fault/off-grid periods excluded (n=870,728): backup_baseline(inv_output) = 11.62 + 0.000877*inv_output, residual std 1.50W. Margin defaults to 5x residual std (~7.5W). At the observed range (0-7500W inverter output) this threshold moves ~19W to ~26W - tune the fields above to compare.

Fixed cutoff regardless of load. 30W default (above the observed 9-28W idle-noise band over the last ~5.8 days); 15W as originally proposed would flicker grey/orange during ordinary idle noise.

Disabled: any backup_ptotal > 0W counts as active. For installs where backup is wired to always carry real load - the idle-noise distinction doesn't apply there, so the heuristic is just turned off.
